## 整句

无需切换模式，连续输入整句后再上屏：`jintiantianqihenhao` 的首选即为「今天天气很好」。
整句打到最后一个字时只敲声母也能提前出整句：`youdiandongx` 的首选就是「有点东西」，与补全成 `youdiandongxi` 一致。

一段拼音分几次选完时，先选的词留在输入框里，整段选完才一起上屏，见 [选错了词](../getting-started/first-input.md#选错了词)。

## 简拼

只敲每个字的声母同样可用：`jttqhh` 出「今天天气很好」。
两三个字母的简拼通常仍按词处理（`sj` 出「时间」），需要整句时多输入几个音节。

## 拼写纠错

- **拼音拼不通时**（多敲、少敲、两键颠倒、敲错一个字母）：`nihooma` → 你好吗，`woxiagnqu` → 我想去，`mingtain` → 明天。
  拼音行把要改动的字母以删除线标出并保留原位，候选全部按纠正后的拼音给出。
  相邻两键颠倒时不必等整个词输完：`mignt`、`migntia` 就已给出「明天」，继续输入即可；
  两种纠正都说得通时优先按颠倒解释（`mignti` → 命题，而不是改一个字母的 面体）。
- **每个音节都对、整句不通顺时**：`meiganxi` 同样可出「没关系」（`gan` 视为 `guan`）。这类纠正只影响整句，不影响单个词的候选。

只有纠正后的句子明显比原样通顺时才纠正；合法的简拼（`nhao`、`womend`）不会被误纠，整段为英文词的输入（`hello`）也不纠正。

### 不需要纠正时

`Enter` 仍将所敲字母原样上屏。原样上屏过一次的字母串，此后不再纠正。

### 记住习惯性错误

被接受的纠正会被记住：习惯将 `shuo` 敲成 `shou` 的话，几次之后「我说」会自然排到前面。用 `Backspace` 删除后改选会一并撤销这次记录。

双拼与五笔下不纠错：双拼敲错一个键改变的是整个声母或韵母，五笔敲的是字根编码，都不是拼错一个字母的情形。

## 本地整句模型

青简随包带一个小模型，在本机为整句候选重新排序，让首选更通顺。全程离线，不联网、不发送任何内容。

- 敲完一段拼音停一下（不到十分之一秒），整句候选就换成模型认为更通顺的那句；没停就先显示按词库算出的句子。
- 模型只调整整句候选；词库拼不出完整句子时，也可能由它补出整句。词候选、你选过的词都不受它影响，你的习惯仍然优先。
- 已经翻到后面的页或用方向键移过高亮时，模型的结果不再换掉正在看的这页。
- 输入法刚启动的几秒钟模型还在加载，这段时间按词库出句。
- 较旧的 Mac（如 macOS 14 上缺少所需图形功能时）改用处理器运行模型，排序可能慢一些。

不想用时，在「设置 → 候选」关闭「本地整句模型」，此后只按词库排序；与 AI 服务互不影响。
换用自己的模型见 [数据文件与日志](../advanced/data-files.md#换用自己的本地整句模型)。
