打字方式不变，仍然按普通话拼音输入；变的只是候选窗口里显示的字与上屏的字。

## 开启

「设置 → 候选 → 输出字形」：

| 选项 | 效果 |
|---|---|
| 简体 | 不转换（缺省） |
| 繁体（台湾） | 台湾用语与字形：软件 → 軟體、这里 → 這裡 |
| 繁体（香港） | 香港字形 |
| 繁体（通用字形） | 标准繁体字形：这里 → 這裏 |

Windows 上还可以打开快捷键，按 `Ctrl + Shift + F` 在简体与繁体之间来回切，见 [改按键](../personalize/keys-settings.md#简繁切换快捷键（Windows）)。

台湾那档先出台湾用语、再出只换字形的写法：打 `ruanjian`，第一个是「軟體」，第二个是「軟件」。香港与通用两档没有用语表，只换字形。台湾与香港的字形取舍不同（裡 / 裏、著 / 着），所以分开两档。改动立即生效。

单字会列出它对应的每个繁体字：打 `gan` 有「幹」「乾」「干」可选。你选过的写法会记住，下次同一个词排第一；选回缺省的那种（台湾那档是用语那条）就恢复原来的顺序。三档分开记。整句候选只出一种写法，台湾那档同样换用语。
AI 给出的候选与整句补全同样转换。Android 在键盘设置里选，见 [Android：生词本与设置](../platforms/android-settings.md)。

## 输入习惯始终按简体记

词库、你选过的词、自己造的词、输入统计记的都是简体。所以：

- 开着繁体输出时学到的词，改回简体输出后照样优先；反过来也一样。
- 删除候选删的也是那条简体记录。
- 你给词选的繁体写法另记一张表，只影响几种写法的先后。
- 候选旁的译词照常显示。

自定义短语按你写下的原文上屏，开着繁体输出也不改字。想要繁体的短语，直接把短语写成繁体。

## 仍按普通话拼音与大陆用词输入

转换发生在候选与上屏这一步，词库本身没有变，因此：

- **读音按普通话**：垃圾要打 `laji`（不是台湾读音 `lese`）、企划要打 `qihua`。
- **用语按大陆习惯**：词库是大陆用词，台湾那档只换得了收录在转换表里的台湾用语；香港与通用两档用语照旧。
- **一字多形的地方偶尔会错**：简体的一个字对应多个繁体字时（后 → 後 / 后、发 → 發 / 髮），转换按词判断，少见的搭配可能选错。遇到错字可以只打那一个字，从它的几个繁体字里选；选过之后单打这个字时它排第一。

需要完整的台湾读音与在地用词时，要另换一套繁体词库，不是这个开关能解决的。
