## 随包词库

基础词库 13 万条，另有通用词库和 11 本领域词库随包：

- 通用词库 150 万条，2 到 30 字，从公开语料里整理出来，还在边用边清洗。缺省开着，在「设置 → 词库」可以关。
  读音一样时，基础词库的词排在它前面；它里面的词也不会在没敲完时提前冒出来，比如敲 `anzhao` 不出「按照规定」，敲全了才出。
- 领域词库：法律、医学、地名、成语、诗词名句、IT、财经、饮食、动物、汽车、历史人物。缺省只开启成语，其余在「设置 → 词库」勾选。

领域词库只影响「是否有这个词」，不改变整句转换的权重。

基础词库收了 3.6 万个生僻字（规范字表以外的扩充汉字与台湾罕用字），用拼音能打出，排在同音字最后，不参与整句转换：
`fiao` 出 覅，`biangbiangmian` 出 𰻝𰻝面。系统字体没有的字会显示成方框。

## 导入用户词库

「设置 → 词库 → 导入词库」，接受三种格式：

- 青简 TSV：每行 `词<Tab>拼音<Tab>词频`，拼音音节间以空格分隔。拼音可以带数字声调（`ni3 hao3`，轻声写 5 或 0），也可以不带（`ni hao`），两种写法打字时一样。
- Rime 的 `.dict.yaml`：读取名称和文件内的词条，词条须为 `词<Tab>拼音[<Tab>权重]`，拼音音节间以空格分隔，非整数权重按 1 处理。不支持 `import_tables` 引用的其他词库、自定义 `columns` 列顺序或 `.schema.yaml` 方案配置。
- 青简 `.qj`：他人制作的词库文件，自带名称与许可证。

TSV 与 Rime 词库导入时，`lue` / `nue` 自动统一为 `lve` / `nve`。词库用 `v` 表示 ü。
旧词库里写成 `lue` / `nue` 的词也照常能打。

导入后列在随包词库之下，显示名称、条数、许可证。可单独开关；「移除」只将文件移到一旁，不删除。

Windows 导入时会转换成 `.qj` 并自动启用，设置页显示导入条数或失败原因。没有可用词条的文件不能导入。
文件选择窗口支持按 Ctrl 或 Shift 多选，批量导入 YAML、TSV 或 `.qj`；单个文件失败不影响其余文件，完成后显示成功、失败数量及各文件结果。
输入法运行时通常在约一秒内自动加载；同名重新导入和移除也会自动更新，无需重启。
若手动编辑配置时出现格式错误，词库仍按上次有效的开关设置加载；修正配置后自动恢复应用新设置。
Rime 文件要经「导入词库…」转换，直接放进词库目录不会加载。

## 导入五笔词库

五笔词库也从「导入词库」进，不用另找入口。导入时看第二列：多字词的第二列是连着写的字母（`gant`）就当五笔词库，带空格的（`kai fa`）是拼音词库。
认不出格式的文件直接报错，不会显示导入成功却打不出来。

五笔词库每行 `词<Tab>编码<Tab>词频`，词频可省略，`#` 开头的是注释；Rime 的 `.dict.yaml` 五笔词库也行。

```text
青简	getu	100
```

- 导入的词跟随包五笔码表合在一起用，不用整份替换码表。同一个编码下按词频排，想让自己的词排在前面就把词频写大一些。
- 词库记给导入时「设置 → 输入 → 形码」选着的方案；形码是「关」时记给五笔（86）。换成别的形码方案后它不生效，换回来照常用。
- 在列表里名字后面带着方案名，例如「wubi-test（五笔（86））」，和拼音词库一样可以开关、移除，导入后马上生效。
- 只有单字的文件分不出是拼音还是五笔，按拼音词库导入。
- macOS 与 Windows 支持；Linux 和安卓还不能导入五笔词库。
